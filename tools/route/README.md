# 巡回員別 効率化ルート生成 (1日7件)

自社巡回業務一覧表から、巡回員ごとに担当物件を **近いエリアでまとめて1日7件の日別ルート** に並べ替えて出力します。

## 使い方

```bash
pip install openpyxl
# 元データ(一覧シートを含む xlsx)を data.xlsx として同じ場所に置く
python generate_routes.py
# -> 巡回ルート_1日7件_巡回員別.xlsx が生成される
```

## ロジック

1. 担当割り当ては元データの「巡回員」列をそのまま踏襲。
2. 各物件の住所から区市を判定し、44区市のおおよその中心座標で
   **最近傍法**により訪問する区の順序を決定（北西から地理的に一筆書き）。
3. 区内は 町名 → 丁目 → 番地 の順にソート。
4. 並んだ順に **7件ずつ** を1日分として日別に区切る。

## 出力

- `サマリー` シート … 巡回員ごとの担当件数・必要日数・主なエリア
- 巡回員ごとのシート … 日／順／物件番号／物件名／住所／エリア／オートロック／緊急キー／備考

## 精度を上げたい場合

住所→緯度経度のジオコーディング結果（各物件の座標）があれば、区中心ではなく
物件単位の座標で最近傍/2-opt 最適化ができ、より短いルートになります。
